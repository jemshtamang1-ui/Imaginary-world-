# Imaginary-world-
The channel which will explain about imaginary things that is impossible in real life

## Videos

- `reels/stars/` — "What if every star disappeared?" A code-built motion-graphics film (Three.js world,
  kinetic type, glass UI, synthesized score and SFX) cut to the voice-over. Preview with
  `cd reels/stars && npm install && node server.mjs 8123` then open http://localhost:8123/.
